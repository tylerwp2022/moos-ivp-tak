# pCoTBridge TLS Certificates

Place the following files in this directory:

  shoreside.pem         — client certificate (BEGIN CERTIFICATE)
  shoreside.key         — client private key  (BEGIN PRIVATE KEY)
  shoreside-trusted.pem — CA certificate      (BEGIN TRUSTED CERTIFICATE)

These are generated by the TAK server and specific to your deployment.
Do NOT commit private keys to version control.

Add to .gitignore:
  ivp/src/pCoTBridge/certs/*.pem
  ivp/src/pCoTBridge/certs/*.key
